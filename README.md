# ainon

英語の細かい用法を、例文と見分け方つきでまとめたノートです。

- [so の三つの使い方](so.md)：結果・目的・程度
- [could は「成功した事実」を言わない](could.md)：現在形の can、過去形の could、so (that) との相性
- [that's why と so の違い](thats-why.md)
- [I'm sure の使い方](im-sure.md)：think との違い、皮肉、that 節が来る仕組み、that 節を取れる形容詞
- 「来る」を極める
  - [第 1 回　「来る」という表現を英語にする](come-1.md)：will come / is coming / comes の使い分け
  - [第 2 回　「来た」という表現を英語にする](come-2.md)：came / is here / has come の使い分け、「来ている」との違い
  - [第 3 回　「来れば」「来たら」を英語にする](come-3.md)：if か when か、現在形か過去完了か、「ば」と「たら」の関係
  - [第 4 回　「来ない」を英語にする](come-4.md)：isn't coming と hasn't come yet の分け方、誘いの「来ない？」
  - [第 5 回　従属節の中の「来る」「来た」](come-5.md)：日本語は主節との前後関係、英語は接続詞で前後を示す
  - [第 6 回　名詞修飾の「来る」「来た」](come-6.md)：関係節の時制、来た人＝who is here、来たことがある＝has been here、シリーズのまとめ
